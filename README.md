# KLHB-FED-26-15-15Household-Water-Usage-Billing-Monitor
Project name: Household-Water-Usage-Billing-Monitor

Team members: kundana reddy : 2620030189

Supervisor's name: Dr. K Sree Rama Murthy

The Household Water-Usage & Billing Monitor is a Java-based application designed to monitor and manage the amount of water consumed by households and calculate their water bills. The system allows users to enter and store water-usage details such as household information, meter readings, and consumption levels.Based on the recorded water consumption, the application automatically calculates the bill using predefined water-rate slabs. It can also maintain billing records, display usage information, and help users understand their monthly water consumption. The system reduces manual calculations, minimizes errors, and provides an easy way to manage household water usage and billing information.The project demonstrates the use of Java programming concepts such as classes and objects, inheritance, encapsulation, arrays/collections, conditional statements, methods, and exception handling. Overall, the application provides a simple and efficient solution for tracking water consumption and generating accurate household water bills.
